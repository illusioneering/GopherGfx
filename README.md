# GopherGfx

GopherGfx is a high-level scene graph library written in TypeScript and WebGL2. It was written by [Evan Suma Rosenberg](https://illusioneering.cs.umn.edu/) for teaching CSCI 4611: Programming Interactive Computer Graphics and Games at the University of Minnesota. The source code also includes contributions from [Daniel Keefe](https://www.danielkeefe.net/) and graduate teaching assistants from the course.

For more information, please see the [online documentation](https://illusioneering.github.io/GopherGfx/).
